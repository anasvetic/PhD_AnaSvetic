# 🔬 PhD_AnaSvetic

### Python scripts accompanying the doctoral thesis of Ana Svetić

Custom Python scripts developed to support the data processing, quantitative analysis and visualisation presented in the PhD thesis by **Ana Svetić**, at **University of Trieste**: 

### From Synthetic to Cell-Derived Plasma Membranes: Developing a Model for Correlative Nanoscale Imaging

## 🎓 Relationship to the thesis

This repository accompanies **Appendix B: Custom Python Scripts** and is the GitHub repository referred to in the thesis as **PhD_AnaSvetic**. The scripts were developed during the doctoral research to support the analysis and interpretation of the experimental results presented in the thesis.

## 📖 Thesis availability
The thesis has been submitted but is **not yet publicly available**. A link to the full thesis will be added here once it becomes available.


## 🐍 Using the scripts
The thesis provides the experimental context, methodological details and interpretation associated with these scripts. When adapting the code to other datasets, users should review the input formats, parameters and assumptions relevant to their analysis.
