Developed to analyse comparative proteomics data from MDA
MB-231-derived GPMVs. Evaluates proteome overlap between 
cells and GPMVs, identifies proteins significantly enriched or 
depleted in GPMVs, performs quality control checks based on 
unique-peptide numbers and abundance ratio reporting limits, 
compares calculated protein subsets with provided reference files, 
and generates graphical and table summaries of the results.
